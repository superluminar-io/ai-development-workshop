# Module 1 Participant Guide

**Claude Code in the Engineering Loop**

> Complete the **Setup** module before starting here.

---

## The scenario

It's your first week at a new company. You've been handed a codebase that processes support tickets and told there's a bug affecting billing customers — no handover, no context, just the repo and a vague description of the problem. Your task is to understand the code quickly, improve what you find, and ship a clean change without breaking anything.

---

## What will you do in this module?

- **Exercise 1 — Codebase Orientation (~18 min):** Explore with Claude, understand slash commands, write your first custom command.
- **Exercise 2 — Writing a Skill (~15 min):** Write a skill Claude applies automatically when the situation matches.
- **Exercise 3 — Safe Refactoring (~22 min):** Improve the code in small steps with Claude proposing and you reviewing.
- **Exercise 4 — Tests, Review, and PR Prep (~18 min):** Find missing coverage, expose and fix a real bug, produce a review and PR summary.
